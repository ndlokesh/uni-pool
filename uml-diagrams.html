# Diagram Purpose
1 Use Case Explains who uses the app and what features they get — great for intro presentations
2 Class Shows all 6 database models and their relationships — good for database design explanation
3 Sequence Step-by-step ride booking flow with all system parts — great for demo walkthroughs
4 Activity Driver's complete journey from login to earning — shows all decision points clearly
5 Deployment Shows where React, Node.js, MongoDB, and Maps live — essential for architecture explanation
